# ADR-0001. Frontend и backend в отдельных репозиториях

Дата: 2026-10-16 · Статус: принято

## Контекст

PRD (раздел 18.1) предлагает монорепо на pnpm workspaces с генерацией клиента и сервера из общего `api/openapi.yaml`.

## Решение

Два независимых репозитория: `orbit-server` (Go) и `orbit-web` (React).

## Последствия

- Каждый репозиторий со своим CI, релизами и инструментами; Go-часть не зависит от Node.js.
- Контракт API живёт в `orbit-server/api/openapi.yaml`. `orbit-web` генерирует типы из опубликованной версии спецификации, а не из соседней папки.
- Изменение API, затрагивающее обе стороны, делается двумя PR: сначала сервер с обратной совместимостью, затем клиент.
