# ADR-0002. Инструменты разработки в отдельном tools/go.mod

Дата: 2026-10-16 · Статус: принято

## Решение

sqlc, goose и golangci-lint закреплены как `tool` в `tools/go.mod` и запускаются через
`go tool -modfile=tools/go.mod …` (обёртки в Makefile). Глобальная установка не нужна, версии одинаковые у всех и в CI.

## Почему не в основном go.mod

golangci-lint и goose CLI тянут сотни транзитивных зависимостей (драйверы всех СУБД, анализаторы).
В основном модуле они смешались бы с зависимостями сервера и влияли бы на их разрешение версий.
